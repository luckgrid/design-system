# Fixtures

Fixtures are small, framework-free examples used by static and browser checks.

- [`plain-html`](plain-html/README.md) exercises the classless base and consumer
  overrides.
- [`brand-theme`](brand-theme/README.md) maps a fictional brand to semantic
  roles.
- [`layouts`](layouts/README.md) demonstrates stack, cluster, and grid.
- [`primitives`](primitives/README.md) covers surfaces, actions, variants, and
  native states.
- [`scoping`](scoping/README.md) proves that public hooks do not leak into
  lookalike or nested markup.
- [`layer-ownership`](layer-ownership/README.md) contains accepted and rejected
  cascade-layer cases for `ds-check`.

`bootstrap-boundary/` contains focused checker inputs rather than a browser
example.
