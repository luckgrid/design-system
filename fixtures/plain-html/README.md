# Plain HTML bootstrap fixture

Classification: **internal**.

This fixture proves only that the public repository can carry self-contained,
semantic HTML and ordinary CSS without a framework, Tailwind, network fetch,
private repository dependency, or Rust requirement in the browser.

`consumer.css` belongs to the fixture. It is **not** a Design System public CSS
entrypoint, token contract, theme contract, or release artifact. DS-E01.S2 owns
those decisions.
